# E-Commerce Product Multi-Filter Application

A modern and responsive e-commerce product browsing application that helps users find products easily using multiple filters and sorting options. The application provides a smooth shopping experience with instant product updates.

## 🚀 Project Overview

The E-Commerce Product Multi-Filter Application allows users to browse products and narrow down their search based on category, price range, and customer ratings. Users can also sort products based on price and ratings.

All filters work instantly without requiring users to click a Submit button.

## ✨ Features

- **Category Filter:** Filter products by categories such as Electronics, Apparel, and Footwear.
- **Price Range Filter:** Select minimum and maximum prices using a dual-range slider.
- **Rating Filter:** Filter products based on minimum star ratings from 1 to 5 stars.
- **Instant Filtering:** Product listings update automatically whenever filters change.
- **Sorting Options:**
  - Price: Low to High
  - Top Rated First
- **Product Cards:** Display product images, names, prices, and star ratings.
- **Clear Filters:** Reset all selected filters and display the complete product inventory.
- **Empty State:** Display a helpful message when no products match the selected criteria.
- **Responsive Design:** Provides a user-friendly experience across different screen sizes.

## 🔍 How It Works

1. The application loads the master product inventory.
2. Users select their preferred categories, price range, and minimum rating.
3. The filtering logic checks products against all active criteria.
4. Only matching products are displayed.
5. Users can sort the filtered products by price or rating.
6. If no products match, an empty-state message and reset option are displayed.
7. Clearing all filters restores the complete product inventory.
